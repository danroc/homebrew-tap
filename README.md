# homebrew-tap

Homebrew formulae for tools by [@danroc](https://github.com/danroc).

## Usage

```sh
brew tap danroc/tap
brew install danroc/tap/<formula>
```

## Formulae

- [`git-stack`](Formula/git-stack.rb) — Manage stacks of interdependent Git branches ([repo](https://github.com/danroc/git-stack))

## Updating

Formulae are updated automatically by release workflows in each tool's source
repository. Manual edits to `Formula/` will be overwritten on the next release.
